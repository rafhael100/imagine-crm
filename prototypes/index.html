Como testar e o que esta demonstração não faz
  1. Abra este arquivo prototypes/index.html no navegador.
  2. Use os seis links acima para examinar cada jornada. Os dados e indicadores pertencem apenas aos exemplos incluídos no repositório.
  3. Experimente a seleção por teclado, filtragem, mudança de etapa fictícia e botões de desfazer. Recarregar a página restaura os exemplos.
  4. Os testes de navegador do projeto verificam desktop e viewport móvel de 320 pixels; esta prévia não substitui homologação de acessibilidade com pessoas reais.
  5. Nenhum resultado desta página concede permissão de negócio, confirma recebimento de lead real ou libera uso em produção.
